# Exp 5: JavaScript Arrays, Objects and Functions

## Files
- script.js: basic arrays, objects, functions
- script2.js: string, array and object methods
- index.html: runs script.js in the browser
- pbl.js: library book manager (addBook, findBook)

## How to run
- node script.js
- node script2.js
- node pbl.js
- Open index.html in a browser and check the console (F12)
